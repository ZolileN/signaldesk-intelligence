5. The classification algorithms
The system can use a combination of:
Supervised classification
For categories where we have labelled examples:
Is this a protest?
Is this a policy change?
Is this an emerging threat?

Models could include:
Transformer classifiers.
Fine-tuned language models.
Gradient boosting on structured features.

Zero-shot classification
Useful at the beginning when we have limited labelled data.
Example:
Text:
"The municipality has suspended approval of the project."

Possible labels:
- Regulatory change
- Political event
- Operational disruption
- Financial event

The model ranks the categories.

Embedding similarity
Every signal becomes a vector:
Signal A → [0.12, 0.84, 0.32...]
Signal B → [0.13, 0.81, 0.35...]

Similarity helps determine:
Are these two signals about the same underlying event or situation?

Graph algorithms
The system can build:
Actor
  ↓
Event
  ↓
Location
  ↓
Organisation
  ↓
Situation

Then analyse:
Central actors.
New connections.
Rapidly growing clusters.
Geographic expansion.
Relationship changes.
